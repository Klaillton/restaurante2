# Segurança

Este repositório é público: não commits segredos, credenciais, chaves nem `.env`.

Para reportar uma vulnerabilidade, abre um aviso privado:

https://github.com/Klaillton/restaurante2/security/advisories/new

Não abras uma issue pública com detalhes exploráveis e não coloques passwords, tokens nem dados pessoais. A correção entra por pull request na `main`.

Ver também [docs/sdd/Security.md](docs/sdd/Security.md).
